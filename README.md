## About Me

I'm a **Senior Fullstack Engineer** with 6+ years of commercial
experience building and scaling web applications across the
Vue.js, React, and Node.js ecosystems, with hands-on experience
in Go services and integrations.

My work spans frontend architecture, backend development,
legacy modernization, performance optimization, and production
delivery.

I'm particularly interested in building maintainable systems,
solving complex engineering problems, and improving the way
software gets delivered.

### AI-First Engineering

I use AI as an engineering multiplier — not as a replacement
for engineering judgment.

My daily workflow with **OpenCode** combines:

- Codebase exploration and dependency analysis
- Data-flow tracing and architectural discovery
- AI-assisted implementation and refactoring
- Test generation and automated verification
- Structured code review and manual validation

The goal is simple: **spend less time on repetitive work and
more time on engineering decisions that matter.**
